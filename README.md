VYou – AI Interview Simulation Platform

📌 Overview

VYou is an AI-powered interview simulation application designed to help students and graduates practise job interviews in a realistic, interactive way.
The system simulates an interviewer that asks role-specific questions and provides feedback on responses.

The goal is to help users improve confidence, communication, and interview readiness before facing real interviews.


🎯 Target Users

ICT students

Recent graduates

Junior software developers

Job seekers preparing for interviews


🧠 What the App Does

Simulates interview-style conversations

Asks dynamic questions based on role and level

Evaluates responses and provides feedback

Offers a safe environment to practise interviews


🚧 Current Limitation / Blocker

At present, the application cannot fully respond as intended due to limited access to AI API tokens.

Most AI inference APIs (including OpenAI and similar providers) require paid API keys, and free tiers are either restricted or unavailable.
This limits the system’s ability to generate real-time AI interview responses during development.

The application architecture is complete and ready to integrate with an AI provider once suitable API access is available.
